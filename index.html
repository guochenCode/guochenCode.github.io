参与 Android / Kotlin 业务开发，重点负责搜索、用户资源和高频点击防护相关体验。

  • 基于 Kotlin Flow + StateFlow 构建响应式搜索架构，使用 MMKV 保存本地搜索历史。
  • 设计 LRU 淘汰策略，仅保留最近 5 条搜索记录，降低历史数据噪声。
  • 使用 EpoxyRecyclerView 构建资源列表 UI，通过 ViewPager2 + TabLayout 实现不同资源类型切换。
  • 封装 OnAntiViolenceClickListener，默认 600ms 间隔防止搜索、取消、清空、历史 Item 等场景重复点击。

参与 Flutter / Android / Dart / Kotlin 项目，为拍摄图片或相册图片添加水印，并支持 POI、裁剪、分享等能力。

  • 支持图片拍摄比例切换、拍摄倒计时、闪光灯、相机变焦等相机能力。
  • 支持默认图片比例、显示语言等数据持久化，并接入水印 POI 地理位置选择与天气状态获取。
  • 使用 Riverpod 管理全局状态与业务逻辑，拆分页面状态和刷新逻辑。
  • 集成 cameraawesome、ffmpeg_kit_flutter_new、extended_image、image_gallery_saver_plus 完成拍照、压图、裁剪和保存。
  • 对接高德 SDK 与知心天气接口，为水印提供周边搜索、关键字搜索和天气数据。
