多人实时协作绘画板

基于自定义 View / Canvas 完成绘图工具，通过 Ktor WebSocket 将同一房间内的画布操作实时同步给多人。

  • MVVM
  • Custom View
  • Canvas
  • Ktor WebSocket

Core implementation

核心实现

  1. 01

    采用 MVVM 设计模式，使用 ViewModel 管理用户、作品与画布状态，结合 ViewBinding、Navigation 完成页面交互和导航。

  2. 02

    基于自定义 View / Canvas 搭建绘画板，统一处理手势采集与图形渲染，支持自由曲线、几何图形、橡皮擦、填色、撤销及移动缩放。

  3. 03

    统一封装图形类型、坐标、画笔样式与轨迹点，将画布修改记录为可序列化操作，用于界面渲染、作品保存和网络同步。

  4. 04

    基于 Ktor WebSocket 实现多人实时协作，本地绘制即时渲染并同步至同房间用户，支持多人同时在线绘制和实时光标同步。
